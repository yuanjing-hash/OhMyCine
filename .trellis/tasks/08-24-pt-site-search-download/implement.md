# 实施计划

1. 添加站点模型、迁移、凭据 purpose 与权限边界。
2. 实现 adapter 接口和 PTTime fixture 解析/受控下载。
3. 实现站点 CRUD、测试、健康和审计。
4. 实现聚合搜索、SSE、结果 token vault。
5. 实现下载桥接和端到端服务测试。
6. 实现站点卡片页与探索页 PT 结果交互。
7. 增加受控推荐图片网关、作品详情 API/页面和标题/TMDB ID 两种搜索身份。
8. 增加 CookieCloud 远程/本地设置、接收、解密、域名匹配、候选测试与周期/手动同步。
9. 把新增站点改为类型向导，并增加 FlareSolverr 兼容的浏览器仿真请求策略。
10. 补充跨层、脱敏、SSRF、迁移与前端交互测试后执行完整 Server/Web UI 质量门。
11. 增加 CookieCloud 受支持域名发现、候选验证后自动建站及新增数量反馈。
12. 增加基于不透明结果 claim 的只读快速识别 API、共享识别/TMDB 降级摘要、同源海报、发行规格与探索页行内结果。
13. 扩展 CookieCloud 安全同步摘要，分别统计其它未支持域名和受支持候选缺少登录 Cookie，并补服务/UI 测试。
14. 增加内建站点目录、共享 NexusPHP adapter、可扩展站点 kind 迁移、目录 API/管理 UI 与 CookieCloud 多站发现；增加多域同步和嵌套表格去重回归测试。
