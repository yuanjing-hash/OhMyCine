# 站点发现与 PT 接入

## Goal

在 OhMyCine Server 中建立真实可用的“发现 → 搜索资源 → 创建下载 → 进入既有整理入库”闭环。公开影视推荐来自独立元数据提供方，PT 站点只负责资源检索和种子获取；两者通过统一作品身份衔接，但不互相绑定。

## Background

- Server 管理端已经预留 `/discovery/recommendations`、`/discovery/explore` 和 `/system/sites`，目前均为计划页。
- 权限目录已经存在 `discovery.read`；下载创建继续使用现有 `downloads.create` 与下载任务权限。
- Server 已有加密 TMDB 凭据、可配置 API/图片地址、TMDB 元数据客户端、AES-GCM 凭据存储、审计、结构化日志、持久任务队列、下载器与媒体库选择、整理入库流程。
- 既有产品决定：PT 站点属于 Server 内建能力；非 PT 内容站点才通过插件扩展。首个真实 PT 站点是 PTTime。
- 推荐页展示公开影视目录，不要求作品预先在某个 PT 站存在。用户打开作品详情或主动点击“搜索资源”时，才并发查询已启用的 PT 站点。

## Requirements

### R1. 产品边界

- 推荐提供方只提供榜单、影视身份、海报、剧情、评分和上映信息，不生成下载地址。
- PT 站点只提供站点连接、搜索、资源详情和受保护的种子获取，不成为推荐元数据唯一真相。
- 推荐作品、手动搜索作品和 PT 搜索结果使用统一媒体类型与外部身份关联；可靠 TMDB ID 优先作为跨来源作品身份，无法可靠匹配时不得仅凭标题强行合并。
- PT 搜索结果创建下载后，必须复用现有下载器、下载暂存目录、目标媒体库顺序/选择、分类 Profile、整理、冲突和入库流程。

### R2. 管理端入口

- “推荐”页展示真实推荐栏目、来源和更新时间。
- “探索”页承载影视搜索、作品详情、跨 PT 站资源搜索与一键下载。
- “站点管理”页承载 PT 站点连接、启停、连通测试、限速/并发、健康状态和凭据更新。
- 不使用占位海报、虚假资源数量或伪造健康状态。

### R3. 可靠性与安全

- 推荐提供方与每个 PT 站点独立超时、限速、缓存和熔断；单个来源失败不阻塞其它来源。
- Cookie、passkey、种子下载凭据和含敏感查询参数的 URL 必须加密保存，并从 DTO、任务普通载荷、日志、审计详情和错误信息中移除。
- 管理员配置站点；具有 `discovery.read` 的用户可以浏览和搜索；创建下载还必须具有现有下载创建权限。
- 所有外部 HTTP 请求必须限制协议、重定向、响应大小、超时和并发，不允许用户把任意 URL 变成 Server SSRF 通道。
- 搜索、推荐刷新、站点测试和下载创建产生可筛选的安全日志；站点配置变更产生审计记录。

### R4. 首版范围

- 首个 PT 适配器为 PTTime，并使用可替换的内建站点适配器接口。
- 推荐首版至少提供电影、剧集、热门趋势、正在上映/播出、即将上映和高分栏目；栏目明确标注数据来源。
- 推荐列表采用缓存优先和用户触发刷新，不进行高频后台刷新。
- 页面支持分页或游标、筛选、空状态、局部重试及来源级错误提示。

## Acceptance Criteria

- [ ] AC1: 管理员可在“站点管理”创建、测试、启停和更新 PTTime 连接，API 与页面从不回显敏感凭据。
- [ ] AC2: “推荐”页显示至少一个真实提供方的电影与剧集栏目，并展示来源和数据更新时间；来源失败时可显示缓存或局部错误。
- [ ] AC3: 用户可从推荐卡片进入统一作品详情，并按需搜索所有已启用且健康的 PT 站点。
- [ ] AC4: “探索”页支持关键词、媒体类型、年份等筛选，PT 结果按站点分组并展示资源大小、发布时间、做种/下载状态、促销与质量摘要等安全字段。
- [ ] AC5: 用户从 PT 结果发起下载时沿用现有下载器与媒体库选择规则；成功创建真实下载任务，并继续进入识别、整理和入库流水线。
- [ ] AC6: 单站点超时、认证失效、限流或返回畸形数据不会阻塞其它站点或使页面整体白屏。
- [ ] AC7: 数据库明文、普通 API、Job payload、日志、审计元数据和 WebSocket 事件均不包含 Cookie、passkey 或含凭据的种子 URL。
- [ ] AC8: 推荐与搜索接口具有 RBAC、no-store/安全缓存边界、请求上限和分页上限；管理操作仅管理员可用。
- [ ] AC9: Server Web UI 在亮色/深色和窄屏下均可操作，所有加载、空、失败、缓存和无权限状态可辨识。
- [ ] AC10: PTTime 适配器、推荐 provider、跨来源身份、限速缓存、安全脱敏、API/RBAC、页面交互及真实下载桥接均有自动化测试。

## Out of Scope

- 本阶段不实现 PT 自动订阅、缺集搜索、自动抢种或刷流。
- 本阶段不允许 PT 站点由社区插件注册。
- 本阶段不把推荐页直接并入 Player 首页；Server API 保持可复用，Player 消费可作为后续独立任务。
- 本阶段不建立新的下载规则系统，也不绕过既有下载和整理任务中心。

## Confirmed Delivery Decision

- 首版 TMDB 与豆瓣双源同时上线。豆瓣使用不包含第三方内置密钥、签名 secret 或移动端伪装凭据的清洁室实现；来源暂时不可用时必须保留 TMDB 和缓存快照，不能拖垮整页。
- PTTime 与推荐页同批交付，并通过“推荐作品 → 聚合搜索 → 安全结果令牌 → 既有下载/整理/入库”完成集成验收。
