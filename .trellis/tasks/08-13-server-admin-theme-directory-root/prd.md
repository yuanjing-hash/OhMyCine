# Server 管理端主题与目录根导航

## Goal

把当前偏深色、玻璃和发光效果的 Server Web 管理端统一改造成更传统、克制且耐看的管理后台，并修复目录选择器进入 Windows 盘符后无法返回盘符列表的问题。首次访问默认使用白色主题，用户可在登录前后随时切换深色主题，选择在当前浏览器持久保存。

## Background

- 当前全局样式、UnoCSS shortcuts、`AppLayout` 和各视图大量直接使用深色、透明白、cyan 渐变、大圆角、模糊与阴影，页面缺少可切换的主题状态。
- 目录选择器已有受 `storages.browse` 双重授权保护的 `GET /api/v1/filesystem/roots` 根列表接口，以及 opaque browse/selection token、限流、超时和 `Cache-Control: no-store`。进入 `D:\` 后，界面只显示不可点击的 `windows` 标签，用户无法从导航区返回盘符列表。
- 根导航可以安全地重新请求现有 roots endpoint，不需要客户端拼接路径，也不需要新增或放宽服务端 token 契约。

## Requirements

1. Server Web UI 首次访问默认使用白色主题；用户可显式切换白色/深色主题，选择保存到当前浏览器，刷新、重新登录和重新打开页面后保持。
2. 不根据操作系统主题自动覆盖默认值或已保存选择。主题切换必须在 Vue 应用挂载前应用到根元素，避免先闪现错误主题；切换时更新 `color-scheme`，让表单和浏览器原生控件匹配当前主题。
3. 登录页、首次 Owner 初始化页、403 页、登录后的 AppLayout、仪表盘、用户/角色/权限、审计、Storage、Planned 页面和目录选择弹窗全部适配两套主题。登录前后都必须有键盘可达、带可理解标签的主题切换入口。
4. 两套主题都采用传统管理后台视觉：纯色页面与侧栏、清晰灰色边框、较小圆角、轻量或无阴影、稳定蓝色强调色、更紧凑的信息密度；移除装饰性径向/大面积渐变、发光、玻璃模糊和大胶囊卡片。
5. 以中文信息层级为主，移除 `SERVER FILESYSTEM`、`Storage foundation`、`Operations first` 等无必要英文 eyebrow/装饰副标题；产品名、版本号、技术类型和确有含义的英文标识可以保留。
6. 颜色通过语义 CSS tokens 和共享组件样式表达，页面不得依赖只适用于深色背景的 `text-slate-*`、`bg-white/*`、`border-white/*` 等散落颜色组合。状态、错误、警告、成功、禁用与 focus 样式在两种主题中都须清晰可辨。
7. 目录选择器根层显示可理解的根导航名称：Windows 使用“此电脑”，Unix/NAS/Docker 使用“文件系统”。进入盘符、挂载点或任意子目录后，该根导航呈现为按钮；点击后重新请求 `/api/v1/filesystem/roots` 并回到盘符/挂载点列表。
8. 目录面包屑继续使用服务端签发 token；根导航不得自行构造 `..`、盘符、UNC 或挂载路径。点击根导航时保留现有请求取消、错误反馈、刷新和焦点可访问行为。
9. 不改变目录枚举授权、路径展示范围、opaque token、安全校验、限流、审计/日志脱敏和 Storage 保存时的服务端重新验证。
10. 保留当前响应式侧栏/移动抽屉、权限过滤、键盘焦点约束和业务功能；视觉改造不得改变路由、权限或 API 行为。

## Acceptance Criteria

- [ ] 清空主题存储后打开登录页或管理端，首屏为白色且没有明显深色闪屏；切换到深色后刷新、登录/退出及重新打开仍为深色，再切回白色同样持久化。
- [ ] 登录、初始化、403、主布局、仪表盘、用户管理、角色权限、审计日志、Storage、Planned 和目录选择器在白色与深色主题下都不存在不可读文字、不可辨边框、透明叠色错误或旧式发光/玻璃背景。
- [ ] 主视觉使用纯色背景、灰色边框、小圆角和克制阴影，主要标题与操作文案以中文为主，页面信息密度较当前实现提高。
- [ ] 主题按钮可通过键盘操作，具有当前状态和切换目标的可访问名称；focus-visible、禁用、成功、警告和错误状态在两种主题下可辨。
- [ ] Windows 流程 `根列表 → D:\ → 子目录 → 此电脑` 能回到所有 Server 可见盘符列表；`D:\` 面包屑仍可返回盘根。
- [ ] Unix/fake adapter 流程进入挂载点或子目录后，点击“文件系统”回到 Server roots 列表。
- [ ] 根导航只调用现有 `/api/v1/filesystem/roots`；子目录和面包屑仍只提交服务端 token，RBAC、no-store、token 用途/有效期及路径安全测试保持通过。
- [ ] `npm run test`、`npm run typecheck`、`npm run lint`、`npm run build`、相关 Go 测试及 `server/test.ps1` 通过，并完成 Windows 真实目录选择与两套主题 smoke test。

## Out of Scope

- 新增更多主题配色、品牌换肤、用户账号级云端主题同步或自动定时切换。
- 自动跟随操作系统 `prefers-color-scheme`；本轮以明确的默认白色和本机用户选择为准。
- 改变 Server API 业务模型、权限体系、目录 token 格式或 Storage/媒体库功能。
- 为目录选择器增加创建、改名、移动、删除、上传、下载、文件预览或任意 UNC 地址输入。
- 重做 Player 的 Cinema OS 视觉；本任务只覆盖 `server/webui`。
