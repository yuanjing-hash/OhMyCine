# 实现已播放状态与继续观看操作

## Goal

统一 Emby/Jellyfin 与 Player 本地媒体的继续观看、完成态和手动标记，并在首页、海报及详情页一致展示。

## Requirements

- 扩展本地历史存储，支持单项标记已播放/未播放、移出继续观看和批量读取完成态。
- Emby/Jellyfin 调用提供方接口并刷新缓存；非 Emby 使用本地数据库。
- 首页继续观看提供继续播放、标记状态和移出操作。
- 电影多版本任一版本完成则作品完成；季/系列仅在全部已知可播放子项完成时完成。
- 已播放海报右下角显示勾，详情页显示状态与切换动作。

## Acceptance Criteria

- [ ] 自动完成和手动完成重启后仍保留，且完成项不在继续观看中。
- [ ] Emby/Jellyfin 服务端状态与 Player 展示一致。
- [ ] 本地/网盘媒体不依赖 Server 即可使用完成态。
- [ ] 单集完成不会误标整季/整剧，聚合规则有测试。

## Out of Scope

- 跨设备同步 Player 本地状态。
