# 修复弹幕匹配并增加手动搜索

## Goal

让 Player 能按弹弹play最新 API 规则可靠地自动匹配并加载只读弹幕；当自动匹配失败或结果不理想时，用户可以搜索并手动选择正确的作品与剧集，同时清晰辨认弹幕当前是开启还是关闭。

## Background

- 最新 Beta 播放《慢慢来》并开启弹幕后，设置顶部出现“一个或多个参数不符合规则”。
- 当前 `POST /api/v2/match` 把带扩展名的文件 basename 作为 `fileName` 发送，而官方最新文档要求文件名不包含文件夹和扩展名，这很可能触发参数校验错误。
- 当前实现只有自动文件识别与获取弹幕流程，没有供用户使用的搜索、番剧详情或手动剧集匹配入口。
- 桌面端和移动端的弹幕开关都用同一个“弹”字，仅用颜色表示状态。

## Requirements

### R1 自动识别遵守最新 API 规则

- 调用 `/api/v2/match` 前从安全的媒体显示名中移除路径和扩展名，只发送文件 stem。
- 不向弹弹play发送本地绝对路径、播放 URL、签名参数、请求头、Cookie 或 DataSource 凭据。
- 保留 `fileNameOnly` 自动识别模式；空 hash 不伪装成有效 hash。
- 自动匹配失败不得中断视频播放，应显示可理解的错误并引导用户手动搜索。
- 多个候选结果不得在没有可靠匹配标记时擅自把第一个结果当作正确答案。

### R2 手动搜索和选择

- 在弹幕设置顶部增加紧凑的“搜索”按钮。
- 搜索结果使用独立响应式窗口承载：桌面端显示 modal，移动端显示全屏页面，避免把大量作品与剧集结果塞进狭窄的设置面板。
- 搜索调用官方 `GET /api/v2/search/episodes`，关键词至少两个字符，并可携带解析出的集号。
- 搜索结果按作品分组，展示可辨认的作品名、剧集标题和剧集编号。
- 用户选择一个剧集后，立即用其 `episodeId` 调用 `/api/v2/comment/{episodeId}` 加载弹幕，并同步当前匹配状态。
- 用户可以在自动匹配结果不正确时重新打开搜索并更换匹配。
- 搜索、无结果、API 错误和加载状态均有明确反馈，失败不得影响播放。

### R3 弹幕开关图标

- 桌面端与移动端都改用内联 SVG 图标，不新增位图资源。
- 开启与关闭必须具有不同轮廓；关闭态使用明确的禁用斜杠，不能只依赖颜色。
- 保留动态 `aria-label`、`title` 和 `aria-pressed`，键盘及读屏状态清晰。

### R4 只读边界

- 仅实现搜索番剧/剧集和读取弹幕。
- 不调用或实现发送弹幕接口。
- 番剧详情接口仅在展示所需信息无法由搜索结果满足时调用，不为消耗 DevCenter 配额而强制调用。

### R5 跨平台和发布兼容

- Rust 命令、TypeScript 服务和 UI 在 Windows 与 Linux 构建路径均可编译。
- 不破坏现有 GitHub Actions 中 Windows/Linux Player 构建和弹弹play密钥注入方式。
- API 凭据不得写入仓库、前端 bundle、测试快照或日志。

## Acceptance Criteria

- [x] 以带目录或扩展名的媒体输入播放时，自动匹配请求只包含清洗后的文件 stem，不再因该参数显示“一个或多个参数不符合规则”。
- [x] 自动匹配成功后可加载并显示对应弹幕；失败时视频继续播放且设置中提供手动搜索入口。
- [x] 用户可输入至少两个字符，查看按作品分组的剧集结果，选择任一剧集并立即加载其弹幕。
- [x] 用户手动选择后，设置区显示的当前匹配与实际加载的 `episodeId` 一致，并可再次更换。
- [x] 桌面与移动端的弹幕开启/关闭图标在形态上明显不同，且无障碍状态正确。
- [x] 没有实现或调用发送弹幕接口。
- [x] 搜索、匹配和评论响应均经过严格解析、超时与大小限制；重定向到评论 CDN 时不泄露官方认证 Header。
- [x] Player 的类型检查、Lint、弹幕验证脚本、前端生产构建及 Rust/Tauri 编译验证通过。
- [x] Windows 本地权威构建通过，并额外验证 Linux/WSL 编译路径或对应 CI 配置未受影响。

## Out of Scope

- 发送、点赞或举报弹幕。
- 弹弹play账户登录或用户弹幕历史。
- 为手动选择结果建立跨设备云同步。
- 为了配额统计而无条件调用番剧详情接口。
- 修改现有 libmpv 跨平台打包方案。

## Technical Constraints

- HTTP 请求继续由 Tauri/Rust 原生层发起，前端不直接持有官方签名密钥。
- 保留自定义 API Base URL 校验、签名鉴权、超时、响应大小限制和受限重定向策略。
- 手动搜索仅发送逻辑标题/清洗后的文件 stem、可选集号及必要查询参数。
