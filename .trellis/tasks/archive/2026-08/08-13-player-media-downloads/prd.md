# 实现下载队列与原始直链下载

## Goal

提供跨平台默认下载目录、“下载到”和可观察下载队列，确保 302/STRM 来源下载真实媒体而非代理内容。

## Requirements

- 设置页可修改默认下载目录；桌面初始为系统 Downloads，Android 使用持久 SAF tree grant。
- “下载”用默认目录，“下载到”临时选择目录；本地文件显示复制到/另存到。
- 原生层按稳定 DataSource 身份重新解析原始 URL/Header，流式写入，不持久化敏感直链。
- 302/STRM 必须下载最终媒体响应，有限重定向并保留安全 Range 语义。
- 下载队列支持总体/文件级进度、取消、重试、空间检查和安全断点续传。
- 聚合项展开文件子任务；Android 使用可见前台状态。

## Acceptance Criteria

- [ ] 默认目录可修改且“下载到”不改变默认值。
- [ ] 302/STRM 下载产物是可播放媒体，不是跳转页或文本。
- [ ] URL、Cookie、Header、签名不进入 Vue、日志或任务数据库。
- [ ] 取消/断电/过期 URL 后不会生成拼接损坏文件，可按身份重新解析恢复。
- [ ] Android 授权失效时明确要求重新选择目录。

## Out of Scope

- 强制依赖 Server 下载器或 PT 管线。
