# 实现媒体删除确认与来源删除

## Goal

用统一确认窗口安全区分“从媒体库移除”和“同时删除源文件”，兼容提供方原生删除及 Player 自有聚合批量删除。

## Requirements

- 点击删除总是打开确认；默认不勾选源删除，仅移出/隐藏媒体库条目。
- 勾选后执行真实源删除；不支持或权限不足时禁用并说明原因。
- Emby/Jellyfin 遵循提供方原生接口和对象范围。
- Player 自有电影多版本、季、系列展开明确的文件清单；季/系列要求输入作品名。
- 伴随文件仅按扫描归属删除，不用模糊 glob；本地防 traversal/symlink escape，网盘由原生 provider command 执行。
- 逐项返回结果，成功项才移除索引，失败项保留并报告。

## Acceptance Criteria

- [ ] 默认删除不触碰源文件，可区分移出继续观看、移出集合与删除媒体。
- [ ] 勾选后本地/已支持网盘真实删除文件，失败不伪装成功。
- [ ] 整季/整剧清单、路径摘要和加强确认正确。
- [ ] 部分失败保持数据库与源状态一致，凭据和完整路径不进入日志。

## Out of Scope

- 为没有安全删除接口的来源使用非官方脆弱请求冒充支持。
