# 修复推荐详情展开白屏

## Goal

修复推荐详情展开季度后白屏，使覆盖率中的季集数据即使包含空数组、缺失字段或局部异常，也只影响对应区块而不会让整个详情路由消失。

## Background

- 用户在推荐详情页点击季度“展开”后，页面主内容区全白，路由仍停留在 `/discovery/details/...`。
- 展开前详情、海报、覆盖统计可正常显示，故故障位于展开后才渲染的 episode 分支。

## Requirements

- 展开/收起不得触发未捕获的 Vue 渲染异常。
- 后端 DTO 与前端恢复边界必须把可空的列表字段规范为安全空数组，不能让模板直接访问 `null.length`。
- 某一集的媒体库引用、名称、日期或状态缺失时，使用安全占位并继续显示其它集。
- 保留现有详情、覆盖率、订阅与资源搜索行为。
- 增加包含生产形状的回归 fixture，不用只覆盖理想化的全字段对象。
- 后端所有覆盖率 collection（顶层库、季度、集、每集库 ID）必须序列化为 `[]` 而非 `null`；前端 API 边界仍兼容旧服务或缓存中的 `null`/缺失字段。
- 季集块提供局部空态/错误态，模板只消费规范化 DTO。

## Acceptance Criteria

- [ ] 展开含多集的季度后页面持续显示，集卡片可见且控制台没有未捕获异常。
- [ ] `library_ids` 为 `null`/缺失/空数组、集名称或播出日期缺失时均局部降级。
- [ ] 连续展开、收起和切换季度不会丢失详情页状态。
- [ ] 后端 JSON 契约测试证明无入库匹配的 `library_ids` 为 `[]`；前端生产 fixture 直接覆盖 `library_ids:null` 与 `episodes:null`。
- [ ] 前端测试、typecheck、lint 和 build 通过。

## Out of Scope

- 重做详情页视觉布局。
- 修改覆盖率缺集判定规则。
