# 实现剧集详情分集标题搜索

## Goal

让用户进入 Series 详情后，可以在该剧全部分集中按标题快速查找并定位目标单集。

## Confirmed Facts

- `player/src/views/MediaDetailView.vue` 当前只保存并渲染选中季的 `episodes`，桌面最多窗口化渲染 8 张卡片，Android 渲染当前季完整列表。
- Series 详情已具备切季、选中单集、滚动定位、续播初选以及进入单集详情的能力，可作为搜索结果定位的既有行为基础。
- 当前未缓存的 Emby/Jellyfin 季需要通过 `source.list(season.id)` 异步加载，跨季搜索不能只过滤当前 `episodes` 数组。

## Requirements

- 在 Series 选集区域标题附近提供搜索按钮，点击后打开与现有 Cinema OS 风格一致的轻量搜索界面。
- 搜索当前 Series 的全部季，而不只是当前已选季；按标题做大小写不敏感、去首尾空白的包含匹配。
- 结果显示季号、集号和标题；标题缺失时使用现有 `episodeTitle` 回退。
- 选择结果后切换到对应季、复用已有分集加载路径、选中并滚动到该集；不得自动播放。
- 搜索加载、无结果、失败、关闭和清空状态均应明确；重复打开可复用本次详情生命周期内已加载的季数据，避免无谓请求。
- 键盘、触摸和屏幕阅读器均可操作，手机布局不能遮挡底部导航或破坏横向/纵向选集设置。

## Acceptance Criteria

- [x] 点击 Series 详情的搜索按钮可输入单集标题，并得到该剧跨季结果。
- [x] 搜索结果包含可区分的季/集编号和标题。
- [x] 选择结果会正确切换季、选中卡片并定位，不会自动播放。
- [x] 清空或关闭后恢复原有选集 UI、选中状态和续播行为。
- [x] 无结果、网络错误、快速重复搜索以及离开详情页不会产生陈旧结果或未处理异常。
- [x] 桌面窗口化选集轨道与 Android 横向/纵向布局均可用。

## Out of Scope

- 搜索简介、演员、字幕内容或文件全文。
- 把剧内搜索结果提升到应用全局搜索页。
