# 统一媒体身份搜索与库覆盖率

## Goal

把 Server Web UI 的默认搜索改成 MoviePilot 风格的“先搜索 TMDB 海报并确认作品身份”，让推荐、关键词搜索、相关作品和类似作品统一进入同一详情页；详情页再基于可信的 `media_type + tmdb_id` 执行受限多语言/别名资源聚合，并显示当前用户可读媒体库中的电影存在状态或电视剧季集覆盖率。

## Background and confirmed facts

- 当前 `DiscoveryDetailView` 已能承载推荐作品详情，但“标题搜索/TMDB ID 搜索”直接跳资源探索页，订阅仍是占位。
- 当前 TMDB 客户端已有 `SearchCandidates`、`GetByID`、替代标题/翻译 enrich 和 `GetTVSeasonEpisodes`；不需要新增第二个元数据 provider 抽象。
- 当前 `SiteService` 已有多站点有界并发、限速、JSON/SSE、安全 `result_token`、识别和 `DownloadService` 交接；媒体身份搜索必须扩展而不是替代这条安全边界。
- 当前 `MediaLibraryEntry` 和 catalog 已保存 `tmdb_id/media_type/season/episode/work_key` 等事实，可以按 actor 可读库聚合覆盖率。
- MoviePilot v3 源码分析见父任务 `research/moviepilot-v3-analysis.md`：默认搜索先进入媒体海报搜索，详情以稳定媒体身份进入资源页，多名称按受限列表聚合，媒体详情展示整季和逐集存在状态。

## Requirements

### R1. TMDB 海报搜索入口

- Server 全局/探索默认搜索提交关键词后返回分页电影和电视剧海报卡片，支持按 `movie/tv/all` 筛选、加载、空态、错误态和取消旧请求。
- 搜索结果只暴露安全 TMDB 摘要和同源图片引用；点击后进入现有统一详情路由，不创建第二套搜索详情页。
- 推荐、TMDB 搜索、相关作品和类似作品产生相同的稳定键和详情 URL。
- 直接 PT/BT 原始关键词搜索保留为明确标注的高级入口，维持单一用户输入查询词，不自动绑定 TMDB 身份。

### R2. 可信媒体身份和名称集合

- 后端对所有身份搜索重新执行 TMDB `GetByID`，只接受 `movie|tv` 和正整数 TMDB ID；不信任浏览器传回的标题、别名、年份或季集信息。
- 共享名称生成器按本地化标题、受支持的中文/地区别名、原始标题、英文翻译及其它替代标题构建有序集合，做 Unicode/空白/大小写等价去重。
- 查询名称有配置常量和硬上限，默认应覆盖主要中文名、原名和英文名；任何单个名称过长、为空或重复都不能进入站点请求。
- 名称生成结果提供安全、可测试的摘要，供 UI 表示本次使用了哪些名称；不得包含上游原始响应或敏感站点数据。

### R3. 多名称资源聚合

- 详情页“搜索资源”调用媒体身份资源搜索，而不是循环调用自由文本 API。
- 服务在现有站点选择、限速、并发、分页和取消约束内执行 `名称 × 站点` 搜索；单名称/单站失败保留其它成功结果并返回安全分组状态。
- 所有候选统一经过现有标题识别、作品/年份/季集约束，再按稳定站点资源身份去重；同一个种子被多个别名命中时只返回一次。
- 合并结果继续只向浏览器提供短期 opaque `result_token`；真实 torrent/magnet URL、passkey 和 Cookie 不进入 DTO、路由、日志或持久缓存。
- 排序稳定，不能因为异步站点完成顺序改变；资源卡片可显示命中名称、站点、标题、大小、做种、发布时间、分辨率、编码和发布组等已有安全字段。

### R4. 跨媒体库覆盖率

- 覆盖率只聚合当前 actor 有权读取且启用的 Server 媒体库，并在输出中使用安全库摘要，不暴露 root path/provider item ID。
- 电影按 `media_type + tmdb_id` 返回 `present | missing | unknown` 与命中库；未扫描或身份事实不足时为 `unknown`。
- 电视剧先获取 TMDB 季和逐集快照，再以确定的 `tmdb_id + season + episode` 对账本地 entries；跨库重复文件只计一个逻辑集，同时可保留命中库列表。
- 逐集状态为 `present | missing | future | unknown`；未播集不是缺失，缺少 air date 或 TMDB/扫描数据不足时不得推断为可下载缺集。
- 每季汇总为 `present | partial | missing | future_or_incomplete | unknown`，返回总集、已入库、已播缺失、未来/未知数和数据新鲜度。
- Season 0 显示为特别篇并默认排除普通缺集汇总，为后续用户显式订阅特别篇保留完整逐集契约。

### R5. 统一详情体验

- `DiscoveryDetailView` 同时展示作品信息、电影存在状态或电视剧覆盖率、相关/类似作品以及资源搜索/下载/订阅入口。
- 覆盖率独立加载，失败不能抹掉作品详情；显示 `未知/待扫描` 和可操作原因。
- 电视剧季卡显示海报、名称、集数和覆盖状态，可展开逐集；移动端和键盘操作可用，不依赖 hover。
- 本子任务只提供订阅入口所需的数据/组件边界，真实订阅创建由子任务 2 实现；在子任务 2 完成前入口保持明确的未就绪状态。

### R6. 权限、兼容和文档

- 媒体搜索/详情沿用 `discovery.read`；覆盖率还必须执行每个媒体库的服务级读取授权，不能仅靠页面可见性。
- 旧推荐详情深链和原始资源搜索 API 保持兼容；Web UI 默认导航改变不等于删除高级路径。
- 新增 API 使用 `/api/v1/` 标准 envelope，安全错误码，不回显查询上游正文或本地路径。
- 更新 Server 设计和 roadmap；实施时再次确认 `server/api/openapi.yaml`，只有存在时才同步更新。

## Acceptance Criteria

- [ ] 输入中英文剧名能看到 TMDB 海报结果，点击进入与推荐卡片完全相同的详情路由。
- [ ] 推荐、TMDB 搜索、相关和类似作品对同一作品产生同一 `media_type + tmdb_id` 身份。
- [ ] 详情资源搜索能按受限中文名/别名/原名/英文名聚合；一个别名或站点失败不丢弃其它结果。
- [ ] 同一资源被多个名称命中时列表只出现一次，排序不受请求完成顺序影响，下载仍使用 opaque token。
- [ ] 高级原始关键词资源搜索仍可用，且只搜索用户输入词、不伪造稳定身份。
- [ ] 电影详情准确显示已入库/未入库/未知及安全库摘要。
- [ ] 电视剧详情按季和逐集准确显示已入库、已播缺失、未来和未知，跨库重复不重复计数。
- [ ] Season 0 明确显示且默认不计入普通缺集；无 air date、未扫描或身份不确定不会显示为可自动下载缺集。
- [ ] 无权限用户不能借覆盖率接口枚举媒体库内容；API、日志和前端状态不泄露路径、凭据或真实资源 URL。
- [ ] 定向 Go/Vue 测试及 Server Web UI test/typecheck/lint/build 通过，架构与 roadmap 同步。

## Out of Scope

- 不实现订阅持久化、调度和自动下载；这些属于依赖本任务契约的子任务 2。
- 不新增 TMDB 之外的海报搜索 provider，不新增 PT/BT 站点 adapter。
- 不实现 episode group、自定义季序或标题模糊匹配驱动的自动缺集判断。
- 不改变 Player 的独立搜索、播放或推荐能力。

## Key Decisions

- 默认搜索先确认媒体身份；原始资源搜索保留但降级为高级入口。
- 身份资源搜索始终后端 `GetByID` 并共享一套名称生成器；浏览器标题不构成信任输入。
- 覆盖率以 OhMyCine 自身 catalog 为事实来源；未知状态 fail closed。
- 特别篇可见但默认排除，只有后续显式订阅才参与自动化。
