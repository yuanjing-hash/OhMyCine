# 统一插件宿主能力与声明式设置页面

## Goal

让第三方插件只负责外部站点特有的登录、发现、解析与元数据能力，下载执行、媒体工具、队列、整理、上传、冲突处理、产物生成和日志全部复用 OhMyCine Server 的受控宿主服务。插件可以声明自己的设置页面，但不能注入任意前端代码。

## Background

- 当前插件下载已由 Server 执行资产下载、DASH 合流和本地暂存，这是需要保留的正确边界。
- `PluginDownloadExecutor.Submit` 当前硬性拒绝非本地目标，导致插件内容不能进入 115 媒体库。
- 115 Driver 当前只有云端移动/复制与“小文件旁挂上传”契约，没有供统一入库流水线使用的媒体文件上传契约。
- 插件 ABI 当前没有插件专属元数据 Provider；下载完成后仍依赖全局 TMDB 识别。
- Manifest 只有 `configSchema`，管理端创建连接时仍要求填写 JSON，缺少类似 MoviePilot `get_form()` 的声明式设置界面。

## Requirements

1. 插件不得自行实现本地、115 或未来云盘的上传和入库逻辑，也不得获得这些连接的凭据。插件只返回受校验的下载计划和插件来源元数据。
2. Server 下载执行器继续统一负责网络资产下载、DASH 合流、字幕/弹幕文件、暂存目录、队列、进度、重试与清理。
3. 目标媒体库由用户发起下载时选择；目标库的转移方式、冲突策略、分类 Profile、命名模板和 Storage 连接快照由 Server 统一解析。
4. 插件 HTTP 下载必须能够进入本地媒体库，也必须能够通过统一 Storage 上传接口进入支持上传的 115 媒体库。115 不支持软链接，云端目标只允许媒体库定义的上传语义。
5. 云端上传必须由 Server 的 Storage Driver 执行，具备目录边界校验、重试、限流、冲突策略、进度、结果对账和可恢复任务状态；插件不能传入本地绝对路径或远端凭据。
6. 新增插件专属元数据能力。该能力只能由产生当前媒体身份的同一插件连接调用，不能参与本地扫库、115 扫库、qBittorrent 或其他插件的普通刮削候选链。
7. 插件元数据在下载任务中保存为带插件 ID、插件版本、连接 ID、Provider 身份和内容身份的不可变快照；插件停用、升级或卸载不得使已确认任务丢失已取得的元数据。
8. NFO/JPG 由 Server 内置产物服务统一生成；插件只提供结构化元数据和受控图片资产引用。Bilibili 普通视频不需要 TMDB 也能生成 NFO，海报和背景图来自 Bilibili。番剧/影视的 TMDB 增强留作显式策略，不允许默认把 Bilibili Provider 注册为全局刮削器。
9. Manifest 支持版本化声明式设置页面。插件可组合宿主白名单中的页签、分组、说明、开关、文本、数字、选择器和凭据/登录状态组件，并将普通字段绑定到连接配置。
10. 管理端必须根据声明式页面渲染插件自己的设置体验，不再要求普通用户编辑 JSON；未知组件、未知字段、越界选项和无效配置必须拒绝或安全降级。
11. 插件不允许注入 Vue、JavaScript、HTML、CSS、裸路由或直接访问 Server 数据库。所有页面动作通过版本化 Host action 和既有 RBAC、审计、凭据加密边界执行。
12. Bilibili 官方插件提供首个真实设置页面，至少包含账号登录/重新登录状态、是否参与主页推荐、默认下载清晰度、字幕和弹幕下载开关及元数据策略说明。
13. 更新 Plugin SDK、Manifest JSON Schema、官方插件模板、架构文档与插件开发文档，确保仓库内外插件实现同一契约。

## Acceptance Criteria

- [x] 安装后的 Bilibili 插件连接使用声明式表单创建和编辑，不要求输入 JSON；扫码登录仍由 Host 加密保存凭据且不回显 Cookie。
- [x] Manifest 中未知或危险 UI 组件无法安装，配置保存时同时通过 JSON Schema 和 UI 字段约束。
- [x] Bilibili 下载选择本地媒体库后继续完成 Server 下载、合流、NFO/JPG 生成和本地入库。
- [x] Bilibili 下载选择支持上传的 115 媒体库后，文件先进入 Server 暂存，再由统一 Transfer/Storage Worker 上传并完成对账；插件代码不引用 115 API 或凭据。
- [x] 本地目标支持媒体库既有移动/复制/链接语义；115 目标拒绝软链接并遵循既有冲突策略。
- [x] Bilibili NFO 包含标题、简介、UP 主、发布日期、BVID/CID 等 Provider 身份；poster/fanart 来自 Bilibili 受控图片资产。
- [x] 普通本地、115 扫描和 qBittorrent 任务不会调用 `org.ohmycine.bilibili` 的元数据能力。
- [x] 下载任务在插件停用后仍可使用已保存的元数据快照继续已进入队列的入库阶段。
- [x] Server Go 测试、Web UI 类型检查/测试/构建、Plugin SDK 合约校验和 Bilibili Rust 测试全部通过。

## Out of Scope

- 允许插件注入任意前端代码或注册裸 HTTP 路由。
- 把 Server 的连接 Cookie、Token 或本地绝对路径交给插件。
- 将 Bilibili 元数据加入全局媒体库扫描刮削候选。
- 在本任务中实现 115 以外尚不存在的云盘 Driver；协议需要可扩展，但只交付已有本地与 115 的真实纵向链路。
