# 修复 Player 下载入口与操作菜单

## Goal

让 Player 只有一个清晰一致的下载概念：用户点击“下载”即创建包含视频、详情快照、海报、字幕和弹幕的完整离线副本，并保证入口、反馈、操作菜单和已下载状态都可正常使用。

## Background

- 媒体详情页同时出现“离线下载”和媒体操作中的“下载”，两个入口实际执行同一功能，造成重复概念。
- 当前下载触发 `Command plugin:dialog|message not allowed by ACL`，导致详情页和媒体操作菜单都无法下载。
- 桌面媒体操作菜单使用固定位置与估算高度，内容较多时超出可视区域，底部操作无法点击。
- 下载完成后应在媒体海报上显示独立于播放完成状态的“已下载”标志，并在删除离线文件后及时消失。

## Requirements

1. 删除媒体详情页独立的“离线下载”按钮，不新增同义入口。
2. 保留统一“下载”操作；该操作继续使用现有完整离线包流程，而不是只下载裸视频。
3. 下载确认与错误反馈不得调用未授权的 Tauri Dialog 命令；应复用 Player 已有的应用内确认框和沉浸式反馈。
4. 桌面右键操作菜单必须限制在当前视口内，标题固定可见，操作列表独立滚动，所有底部操作可触达。
5. 海报“已下载”标志必须由本地离线索引的稳定来源/媒体身份计算；完整下载显示“已下载”，剧集部分下载显示数量或比例，删除离线文件后刷新消失。
6. 不修改 Server，不改变现有下载队列、完整离线包内容或在线播放流程。

## Acceptance Criteria

- [x] 媒体详情页不再显示“离线下载”按钮。
- [x] 右键/长按菜单中的“下载”可以正常进入确认并加入下载队列，不再出现 `plugin:dialog|message not allowed by ACL`。
- [x] 桌面窗口高度不足时，媒体操作菜单不会超出屏幕，列表可以滚动到底并点击全部操作。
- [x] 已完成下载的电影或单集海报显示“已下载”；部分下载的剧集显示正确数量或比例。
- [x] 删除对应离线文件后，相关海报标志在索引刷新后消失。
- [x] Player typecheck、lint、build 以及相关专项测试通过。
- [x] `git diff --name-only -- server` 为空。

## Out of Scope

- 重写下载队列、网络传输或附件下载实现。
- 新增第二套“仅视频下载”模式。
- 修改 Server 下载或媒体入库逻辑。

## Key Decisions

- 产品层只使用“下载”这一名称；它等同于完整离线下载。
- 确认与反馈优先使用应用内组件，避免把核心流程依赖于原生 Dialog ACL。
- “已下载”与“已播放”是两个独立状态和视觉标志。
