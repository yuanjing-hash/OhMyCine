# 新增 Server 媒体库浏览管理

## Goal

在不改变现有媒体库配置能力的前提下，为 Server 管理端新增面向内容的媒体库海报墙、作品详情、元数据维护和受控源文件删除，让用户可以按库查看真实入库覆盖并完成日常维护。

## Background

- 当前“系统 > 媒体库”承担连接、根目录、扫描和识别配置，不适合作为日常内容浏览页。
- Server 已有单库 catalog、作品详情、识别候选、人工 TMDB 覆盖和重新整理能力，应组合这些读模型和动作，而不是新增第二套扫描索引。
- 用户希望发现侧栏增加类似 Player 的媒体库页面，并能从作品详情修改匹配、重新刮削、删除源文件。

## Requirements

### 导航和浏览

- 保持 `/system/media-libraries` 路由和现有配置能力不变，仅将侧栏文案改为“媒体库管理”。
- 在“发现”分组新增“媒体库”入口，页面顶部支持“全部库”和各启用媒体库切换。
- 单库视图复用现有 catalog；“全部库”必须由后端按稳定作品身份去重并正确分页，不能由前端拼接各库第一页。
- 支持电影、电视剧和现有分类筛选、搜索、分页、加载/空/局部错误状态；海报与背景使用 Server 安全同源投影，不暴露 TMDB 原始 URL、115 路径或签名直链。
- 海报进入管理端作品详情，视觉和信息结构与推荐详情一致，并展示所选库或全部库中的真实文件、季集覆盖及匹配状态。
- 推荐详情与媒体库详情抽取共享 hero/季集覆盖展示组件和规范化 DTO，避免复制易漂移的模板。

### 元数据维护

- “修改元数据”使用现有 TMDB 候选与 `(media_type, tmdb_id)` 人工覆盖，不提供任意不可信字段自由编辑。
- “重新刮削”重新请求当前作品元数据并刷新 catalog/artifact 投影，默认不移动或重命名源文件。
- “修正识别并重新整理”仍走现有 preview/confirm/persistent job，不与普通重新刮削混为一个动作。
- 所有作品级动作由后端用 opaque work token 重新解析当前 entry 和 recognition revision；前端不得拼接数据库 ID。

### 源文件删除

- 删除只作用于当前选中的媒体库与当前作品；“全部库”详情必须先明确选择要删除的库，禁止跨库级联。
- 使用独立权限 `media_libraries.media_delete` 和独立 preview/confirm API，不能复用“删除媒体库配置”的权限或路由。
- Preview 展示库、数据源、作品、文件数、总大小、安全相对路径摘要和 STRM 影响数，签发短期、单次、绑定 actor/work revision 的不透明确认 token。
- Confirm 重新校验 token、权限、library/work revision、entry 集合、根目录归属和 provider 身份；状态漂移、歧义、路径越界、符号链接/Reparse Point 逃逸、跨库目标均失败关闭。
- 本地只删除 preview 中且仍位于库根内的文件，空目录只在仍位于库根内时清理。
- 115 只使用对应 Connection 的受控回收操作，删除后文件从媒体库数据源中移除并进入 115 回收站；本轮不自动清空云端回收站。
- Provider 操作成功后再收敛 catalog/manifest，排队 STRM reconcile/cleanup 和 Emby/Jellyfin refresh；部分成功必须持久化逐项进度并可幂等续跑。
- 审计只记录库、作品 token hash、数量、provider 类型、结果和安全错误码，不记录绝对路径、provider ID、Cookie 或 URL。

## Constraints

- 本轮是 Server 管理端功能，不修改 Player 的独立媒体库页面。
- 至少覆盖本地和 115；其他驱动仅在已存在且能证明一致安全删除语义时复用。
- 作品浏览使用既有扫描事实，不从页面请求直接重新遍历数据源。

## Acceptance Criteria

- [ ] 原“媒体库”配置入口显示为“媒体库管理”，路由、配置、扫描和识别功能保持不变；发现侧栏出现新的“媒体库”。
- [ ] 用户能切换全部库和单库，并按类型/分类正确搜索、筛选和分页；全部库按稳定身份去重且总数准确。
- [ ] 海报详情展示真实库内文件和季集覆盖；空/null/部分数据只局部降级，不导致页面白屏。
- [ ] 管理员能通过现有 TMDB 候选修改匹配、清除覆盖和重新刮削，普通重新刮削不移动源文件。
- [ ] 删除 preview 精确展示当前单库作品影响范围，confirm token 过期、复用、actor 不符、revision 漂移、越界和跨库目标均被拒绝。
- [ ] 本地和 115 删除均只作用于 preview 中的源文件；115 文件进入回收站，删除成功后 catalog、STRM 和媒体服务器刷新最终一致。
- [ ] 部分 provider 成功可幂等恢复，数据库不会先于源文件删除而丢失恢复事实，审计与 API 不泄露敏感路径/身份。
- [ ] Go 测试、Web UI 测试、typecheck、lint、build、OpenAPI 与相关架构/安全文档更新通过。

## Out of Scope

- 重做媒体库配置页或 Player UI。
- 任意字段自由编辑器、批量跨库删除、自动清空 115 回收站。
- 一次性补齐所有未来云盘驱动的删除能力。
