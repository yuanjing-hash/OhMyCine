# Player Server 分步搜索入库工作流

## Goal

把 Server TMDB 海报详情中的资源搜索与入库改成清晰、渐进、可追踪的 Player 工作流，并统一为 Cinema OS 玻璃界面。

## Requirements

- 详情页只保留 AppLayout 的单一返回按钮，返回搜索工作区而不是首页。
- “搜索”和“直接搜索”先打开站点选择弹窗，支持快速全选；直接搜索继续支持标题和 TMDB ID。
- 确认站点后打开独立结果工作区。站点并行搜索，某站返回后立即展示，不等待全部站点。
- 顶部仅为有结果的站点生成横向页签；空结果、失败和运行状态在独立状态区展示。
- 每个站点维护独立客户端分页，切换站点不会重置其它站点页码。
- 单条资源使用“选择入库”，后续步骤依次为选择下载器、选择媒体库、确认。
- 下载器与媒体库均先展示“默认”选项，并平铺列出当前账号可用的全部选项；默认项自动选中。
- 提交成功后在详情页立即展示排队、下载、整理、刮削、入库、失败等阶段并持续刷新。
- 右侧悬浮工具条新增“Player 入库任务”，打开当前账号跨已连接 Server 聚合的入库任务面板。
- 目标媒体库存在非终态任务时，在媒体库分类顶部显示“正在入库”，并以不可播放占位海报展示当前阶段与进度；任务完成后由真实扫描结果接替。
- 订阅功能、权限门禁、搜索取消、失败站点重试保持可用。
- 从 TMDB 海报发起的任务携带期望媒体身份；身份不一致时不得静默入错库，应阻止提交或进入需要确认状态。

## Acceptance Criteria

- [x] 页面无双返回，点击返回可恢复搜索主页及原搜索状态。
- [x] 流式返回的首个有结果站点会在搜索仍进行时出现。
- [x] 结果页签只包含有结果站点，每站分页互相独立。
- [x] 入库确认严格按下载器、媒体库、确认三步执行，默认项已选。
- [x] 提交后详情页和右侧任务面板立即出现任务状态，并可刷新到终态。
- [x] 目标库可立即看到“正在入库”占位海报，且占位内容不会暴露不可播放操作。
- [x] 直接标题、直接 TMDB ID、多语言聚合搜索及订阅均无回退。
- [x] 无对应能力的账号不能搜索、入库或查看越权任务。
- [x] Player 类型检查、Lint、构建与 Server DataSource 验证通过。
