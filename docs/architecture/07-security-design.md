# OhMyCine Player 安全设计

本文只描述 Player 的安全边界。Server 的账号、插件、网盘、下载整理和图片代理安全契约由 [Server 安全设计](https://github.com/yuanjing-hash/OhMyCine-Server/blob/develop/docs/architecture/07-security-design.md) 维护。

## 需要保护的数据

- Server 设备令牌、Emby/Jellyfin 凭据、字幕服务凭据和其他用户密钥。
- 用户本地视频路径、Android SAF URI、播放历史、下载目录及离线附件。
- Server 管理的上游播放与图片地址，以及可能包含签名的短期 URL。

普通数据源配置只保存非敏感字段与凭据引用。桌面和移动端通过原生安全存储边界管理凭据；标准与便携配置档案互相独立。日志、导出、诊断和报错不应包含令牌、Cookie、密码、签名 URL 或本地绝对路径。

## 数据源与认证

Player 只允许用户配置 Server、Emby、Jellyfin。内部 `offline` 源用于已完成下载。旧网盘、WebDAV、CloudDrive2、123、夸克和本地文件夹配置在升级时清理；不能通过旧配置恢复这些适配器。新增连接先验证，再保存非敏感配置和安全凭据引用。停用或删除连接时，按精确 `sourceId` 隔离其缓存、历史和偏好，不影响其他来源。

Server 设备 Bearer 只发往配置的 Server 同源 API。Emby/Jellyfin 令牌只用于各自服务器。播放、字幕、弹幕和 DASH 音频的重定向若跨源，必须丢弃私有 Header；不得把凭据传给 CDN 或在线插件上游。

## Server 图片

Server 的实体媒体、在线插件、发现结果、人物、剧照、版本和历史图片只通过 Server 签发的受保护引用进入 Player。Player 校验图片 URL 属于当前 Server 同源且路径在明确的图片路由白名单内；拒绝 userinfo、非 HTTP(S)、跨源 URL 和插件/TMDB 外链。原生请求在该边界附加设备认证，按需取图并写入有容量上限的缓存；缓存键不包含凭据，源或凭据变化后隔离旧缓存。离线下载同步保存图片附件，断网时读取本地副本。

在线插件图片的网络权限、DNS/重定向和内容校验由 Server 执行。Player 不能把插件 URL 交给 WebView 图片标签或绕过 Server 代理。Emby/Jellyfin 图片保留在各自服务的读取边界。

## 本地文件与 Android SAF

本地播放只接受用户明确选择的单文件、多文件或文件夹。文件夹只读取直接子级的视频文件。桌面原生命令规范化路径并限制到选择的目录；Android 通过 SAF 保留只读授权，拒绝目录穿越，将 `content://` URI 只交给原生描述符播放，不写入路由、日志或持久媒体库。没有源文件删除或写权限操作。本地临时队列仅在当前会话存在；本地播放进度和字幕偏好按已有受控缓存保存。

## 下载、离线与升级

仅 Server、Emby、Jellyfin 可规划新下载。下载任务存储稳定源身份与受管理的目标文件名，不保存短期流 URL、Bearer、Cookie 或重定向 Header。取消或升级清理只删除本应用明确拥有的 partial 文件；已完成影片、图片、字幕和用户其他文件不能被清理。Android SAF partial 删除失败保留延迟清理记录，启动时先尝试重试，再恢复仍受支持的任务队列。

旧来源配置迁移在写入过滤后的连接列表前保存待清理标记。清理历史、偏好、收藏关联、导航、凭据和扫描缓存每步可重复执行；失败保留标记供下次启动继续。原生下载迁移先于队列恢复。已完成离线包和本地文件播放记录保留。

## 运行与验证

使用隔离的标准/便携测试档案做迁移和实际播放检查，不能清空用户现有档案。验证 Server 图片权限与插件网络范围、Player 同源图片限制、重定向私有 Header 隔离、离线附件、旧来源迁移、路径约束和 Android 只读 SAF。类型检查、Lint、构建和 Cargo 检查不能替代真实桌面与 Android 播放验收。
